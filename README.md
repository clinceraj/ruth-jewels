# RUTH-JEWELS

HANDPICKED INDIAN CLASSICAL JEWELERIES SHOP

## About

Ruth Jewels is an e-commerce website dedicated to handcrafted South Indian jewelries. Each piece in our collection represents the heritage and tradition of classical Indian jewelry-making, presented with a modern, elegant finish.

## Features

- **Extensive Collections** - Featured galleries of various jewelry pieces
- **Custom Orders** - Request custom-designed pieces
- **Instagram Integration** - Easy connection to our Instagram for ordering
- **Responsive Design** - Beautiful on all devices

## Setup Instructions

To set up this repository locally:

```bash
git clone https://github.com/clinceraj/ruth-jewels.git
cd ruth-jewels
```

## Local Development

Open `index.html` in your web browser, or use a local server:

```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## GitHub Pages Deployment

1. Go to repository **Settings**
2. Navigate to **Pages** section
3. Set Source to `main` branch
4. Your site will be live at: `https://clinceraj.github.io/ruth-jewels/`
